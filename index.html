Material de Apoyo al Expositor

Cómo explicar este proyecto en tu presentación de IA

Usa esta guía estructurada para demostrar cómo la Inteligencia Artificial Generativa aceleró el desarrollo de software real en segundos.

1

Ingeniería de Prompts (La Instrucción)

Explica a tu audiencia que no programaste línea por línea desde cero, sino que actuaste como Arquitecto de Software dándole contexto específico a la IA:

"Crea una aplicación de calculadora para calcular los Bolívares en Dólares según el precio oficial del BCV usando HTML, CSS y JS en un archivo integrado..."
Concepto clave: Del lenguaje natural al código ejecutable.
2

Tecnologías Integradas (Single-File)

Menciona cómo la IA combinó tres pilares del desarrollo web moderno dentro de un solo archivo portátil sin necesidad de servidores complejos:

  • HTML5 Semántico: Estructura accesible.
  • Tailwind CSS: Diseño responsivo y modo oscuro.
  • JavaScript ES6+: Cálculos en tiempo real y conexión a API (`fetch`).
Ventaja: Cero latencia y funciona incluso sin internet una vez abierta.
3

Más allá de lo básico (UX/UI)

Destaca que la IA no solo hizo una multiplicación simple, sino que infirió las necesidades reales de un usuario en Venezuela:

  • Conversión bidireccional automática (Bs. ↔ USD/EUR).
  • Consulta automática de API de tasa BCV con respaldo manual.
  • Cálculo de IVA (16%) e IGTF (3%).
  • Botón para copiar resumen listo para WhatsApp / Pago Móvil.
Impacto: Reducción del tiempo de desarrollo de días a minutos.

Guion sugerido para tu exposición (1 minuto)

"Buenas tardes. Para demostrar el potencial práctico de la Inteligencia Artificial en el desarrollo de software, le pedí a un modelo de IA que creara una solución a un problema cotidiano en nuestro país: el cálculo rápido y exacto de divisas a la tasa oficial del Banco Central de Venezuela.

Con una sola instrucción en lenguaje natural, la IA diseñó e integró en un único archivo el diseño visual responsivo, la lógica matemática en JavaScript y la conexión en tiempo real con la tasa del BCV. Como pueden ver en pantalla, si escribo 20 dólares, calcula instantáneamente los Bolívares, desglosa el IVA y me permite copiar el monto exacto para realizar un Pago Móvil. Esto demuestra que la IA no reemplaza al creador, sino que multiplica nuestra productividad."
